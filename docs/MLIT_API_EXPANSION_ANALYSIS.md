## 2. 미수집 레이어 우선순위 분석

### 평가 기준
- **독자 실용성**: 실거주자·투자자의 의사결정에 직결되는가

- **수집 난이도**: 기존 파이프라인 대비 추가 공수

#### XPT001 — 不動産価格 포인트 API (위치정보 포함)

**분류**: 가격 정보 | **데이터 범위**: 2005년 Q3 이후 (취득가), 2021년 Q1 이후 (성약가)

**현재 XIT001과의 차이**  
XIT001은 시구정촌 단위 집계값만 반환. XPT001은 **거래 건별 위도·경도**가 포함된 GeoJSON 포인트 데이터. 즉, 동일한 원천 데이터를 공간 정보가 붙은 형태로 제공한다.

**조합 분석 아이디어**

1. **역세권 프리미엄 정밀 정량화**  
   XKT015(역별 승하차) × XPT001(거래 좌표) → 각 거래 건에 "가장 가까운 역까지 도보 분" 계산 → "도보 1분 = 가격 X만원 차이" 라는 구체적 수치 도출.  
   현재는 구 단위 평균뿐이라 역세권 분석이 불가능. 이 레이어 추가 시 에피소드 내 가장 강력한 단독 분석이 된다.

2. **구 내 가격 지도 작성**  
   같은 구 내에서도 町名·丁目 단위 가격 분포를 시각화 가능. "北区 내에서 가장 싼 町名 vs 가장 비싼 町名" 분석.

3. **재해구역 × 실거래 가격 교차**  
   XKT025~029(재해 상정구역)와 공간 조인 → "홍수 상정구역 내 거래 vs 구역 외 거래" 가격 비교를 실거래 건 단위로 산출. 현재는 구 단위 평균으로 추정만 가능.

**수집 난이도**: 낮음 (XIT001과 파라미터 구조 동일, 출력 형식만 GeoJSON)

#### XCT001 — 鑑定評価書情報 API

**분류**: 가격 정보 | **데이터 범위**: 지가공시 직근 5년분 감정평가서 원문

**현재 보유 데이터와의 차이**  
XPT002는 지가 수치만 제공. XCT001은 감정사가 작성한 **평가 근거·주변환경·장래동향 코멘트**까지 포함된 원문 데이터.

**조합 분석 아이디어**

1. **지가 상승·하락 이유의 1차 소스화**  
   XPT002(지가 CAGR 수치) × XCT001(감정 코멘트) → "北区 赤羽 주변 지가 +7.3% CAGR의 배경 = 재개발 計画進行中 (출처: 감정평가서 2025년)"과 같은 직접 인용 가능. 블로그 신뢰도 최고 수준 보강.

2. **구별 장래동향 텍스트 분석**  
   감정사 코멘트의 "上昇"·"横ばい"·"下落" 패턴 집계 → 구별 시장 심리 지표 생성.

3. **표준지 특성 정보 활용**  
   용도지역·건폐율·용적률·전면도로 폭 등 개별 지점의 상세 조건을 직접 확인 가능.

**수집 난이도**: 중간 (JSON 반환이지만 텍스트 파싱 처리 필요)

#### XKT003 — 立地適正化計画 API

**분류**: 도시계획 | **데이터 범위**: 令和6년도 GIS데이터

**핵심 개념**  
일본 정부가 인구감소 시대를 대비해 지정한 "공식 거주 권장 구역" 지도.  
- **거주유도구역**: 인구밀도 유지를 위해 거주를 유도하는 구역. 구역 내는 인프라 유지 보장.  
- **도시기능유도구역**: 병원·상업·행정 등 생활기능을 집적 유도하는 구역.  
- 구역 **밖**은 장기적으로 인프라 축소·행정서비스 감소가 공식 예정.

**조합 분석 아이디어**

1. **장기 투자 리스크 필터**  
   인구 추계(社人研) × 입지적정화계획 → "인구감소 예정 + 거주유도구역 밖" = 최고위험 조합 지역 식별.  
   반대로 "거주유도구역 내 + 현재 저평가" = 정책 지원 수혜 가능 매수 기회.

2. **에피소드 콘텐츠 각도**  
   한국 독자에게 생소한 일본 특유 개념. "일본 정부가 공식으로 '여기서 살아라'고 정한 지도가 있다" → 강력한 훅. 차별화 콘텐츠.

3. **구별 커버리지 비율 산출**  
   각 구 면적 대비 거주유도구역 커버리지 % 계산 → 구별 "정책 안전도" 지표.

**수집 난이도**: 낮음 (타일 GeoJSON, 기존 파이프라인과 동일 방식)

#### XST001 — 災害履歴 API

**분류**: 방재 정보 | **데이터 범위**: 국토조사 토지이력조사 (조사 완료 지역 한정)

**현재 방재 5종과의 차이**  
XKT025~029는 **"앞으로 발생 가능성"** (상정구역·확률 기반).  
XST001은 **"과거에 실제로 발생한 기록"** (재해 이력).  
이 두 레이어를 교차함으로써 리스크를 4분면으로 정밀 분류할 수 있다.

| | 이력 있음 | 이력 없음 |
|---|---|---|
| **상정구역 내** | 🔴 최고위험 (실적+예측) | 🟠 주의 (예측만) |
| **상정구역 외** | 🟡 유의 (이력만, 구역 재검토 가능성) | 🟢 저위험 |

**조합 분석 아이디어**

1. **리스크 4분면 매핑**  
   위 표를 23구 단위로 적용 → "江東区는 상정구역 내 + 이력 있음 = 최고위험" vs "文京区는 상정구역 일부 + 이력 없음 = 주의 수준"

2. **"위험하다고 하는데 실제로 일어난 적 있나"**  
   독자가 가장 궁금해하는 질문에 1차 소스로 답변 가능.

3. **가격 디스카운트 정당성 검증**  
   이력 있는 구역이 실제로 가격 낮은가 → 시장이 과거 재해를 반영하고 있는지 검증.

**수집 난이도**: 중간 (조사 미완료 지역은 데이터 공백 존재, 커버리지 확인 필요)

#### XGT001 — 指定緊急避難場所 API

**분류**: 방재 정보 | **데이터 범위**: 令和8년 3월 기준

**핵심 개념**  
재해 발생 시 주민이 피신하는 지정 긴급대피장소. 수용 가능 인원·대응 재해 종별(홍수/지진/쓰나미 등) 정보 포함.

**조합 분석 아이디어**

1. **재해 위험 × 대피 인프라 교차 분석**  
   XKT025~029(재해 위험도) × XGT001(대피장소 밀도·수용 인원) → "위험하지만 대피 인프라가 충실한 구" vs "위험하고 대피장소도 부족한 구" 구분.  
   같은 홍수 위험이라도 대피장소가 촘촘한 구는 실거주 관점에서 다르게 평가.

2. **1인당 대피 수용 인원 지표**  
   구별 인구(住民基本台帳) ÷ 대피장소 총 수용 인원 → "1인당 대피 여유도" 지표. 구별 랭킹화 가능.

3. **재해별 대피장소 커버리지**  
   홍수 대응 지정 장소 vs 지진 대응 지정 장소가 다를 수 있음 → 재해 종별 커버리지 비교.

**수집 난이도**: 낮음 (포인트 GeoJSON, 기존 파이프라인과 동일 방식)

#### XKT016 — 災害危険区域

**분류**: 방재 | 건축기준법 제39조 기반 지자체 자체 지정 구역.

**핵심 차이점**  
XKT025~029가 국토교통성 기준이라면, XKT016은 **도쿄도·각 구청이 독자 지정**한 위험구역.  
두 레이어의 불일치가 흥미로운 분석 포인트:  
- 국가는 위험 상정 → 지자체는 미지정: "행정이 위험을 과소평가하는 지역"  
- 지자체 지정 → 국가 상정 없음: "지역 사정을 아는 구청만 알고 있는 위험"  

→ 두 레이어 교차로 "숨겨진 위험 구역" 발굴 가능.

#### XKT014 — 防火・準防火地域

**분류**: 도시계획 | 방화·준방화지역 경계.

**투자자 관점 핵심**  
방화지역 내 = 목조 신축 불가 (철근콘크리트·철골 의무) → **재건축 비용이 일반 지역의 1.5~2배**.  
같은 용도지역이라도 방화지역 내 노후 건물은 재건축 수익성이 다르게 계산됨.  
XKT002(용도지역) + XKT014(방화지역)를 함께 보아야 개발 포텐셜 분석이 완전해진다.

#### XKT030 — 都市計画道路

**분류**: 도시계획 | 도시계획도로 계획선·정비 현황.

**양면성 분석**  
- **수용 리스크**: 계획선 상의 건물은 언젠가 수용 대상. 해당 필지 내 건물은 **건축 제한** (계획선 내 2층 이하·불연재료만 허용). 가격 디스카운트 요인.  
- **가격 상승 기대**: 계획도로 완성 예정 지역 인근은 접근성 향상 → 가격 상승 기대.  
XPT001(거래 좌표) × XKT030(계획도로) → 계획선 인접 여부별 가격 비교 가능.

---

#### XKT023 — 地区計画

**분류**: 도시계획 | 소구역별 세부 건축 규제.

**용도지역보다 세밀한 레이어**  
같은 "상업지역"이라도 지구계획 유무·내용에 따라:  
- 벽면후퇴 의무 → 저층 상가가 줄지어 선 거리 경관 유지  
- 높이 제한 → 초고층 불가  
- 용도 제한 → 풍속업 등 불가  

재개발 가능성 정밀 분석에 필수. "같은 구라도 지구계획 적용 구역은 재개발이 어렵다" vs "미적용 구역은 개발 여지 크다"는 투자 각도.

---

#### XKT024 — 高度利用地区

**분류**: 도시계획 | 용적률 특례 구역.

**재개발 포텐셜 직접 지표**  
고도이용지구 내는 통상 용적률을 초과하는 개발이 허용 (예: 상업지역 600% → 800% 이상).  
즉, 이 레이어에 포함된 지역 = **법적으로 더 큰 건물을 지을 수 있는 곳** = 재개발 수익성 높음.  
XPT001(거래 좌표)와 조합 시 "고도이용지구 내 저가 매물 = 재개발 프리미엄 미반영 저평가" 탐지 가능.

---

#### XKT020 — 大規模盛土造成地

**분류**: 지형 정보 | 대규모 성토 조성지.

**버블기 택지개발 유산**  
1960~80년대 고도성장기에 산을 깎아 만든 대규모 택지. 지진 발생 시 성토부분이 붕괴·활동할 위험.  
XKT025(액상화) × XKT020(성토지) → **지반 이중 위험 지역** 식별.  
23구보다 타마·수도권 외곽에 많으나, 대田区 등 일부 구에도 존재.

#### XKT004·005 — 小学校区·中学校区

**분류**: 주변시설 | 초·중학교 학구 경계.

"학군 × 집값" 분석. 도쿄는 한국만큼 학군 영향이 크지 않지만, 文京区·世田谷区 등 일부 구에서는 유의미한 상관관계가 알려져 있음.  
XPT001(거래 포인트)와 공간 조인 시 "학구 내 vs 학구 외" 가격 비교 가능.  
**독자 훅**: "도쿄 엄마들이 집을 고를 때 학군을 따진다? 데이터로 확인해봤다"

#### XKT006·007 — 学校·保育園·幼稚園

**분류**: 주변시설 | 학교·보육원 위치 포인트.

#### XKT010 — 医療機関

**분류**: 주변시설 | 병원·의원 위치.

구별 의료기관 밀도 → "생활 인프라 종합 지수" 구성 요소.  
특히 고령자·장기 거주 관점에서 중요. XKT011(복지시설)과 함께 묶으면 "노후에 살기 좋은 구" 랭킹 콘텐츠 가능.

#### XKT031 — 人口集中地区(DID)

**분류**: 인구 정보 | 인구집중지구(인구밀도 40인/ha 이상 연속지역) 경계.

23구 내는 거의 전역이 DID이므로 구분 실익이 낮음.  
**시리즈 확장 시 가치**: 도쿄 외곽·수도권 분석으로 시리즈 확대 시, "실제 생활권 경계"와 "행정구역 경계"의 괴리를 보여주는 데 필수.

#### XKT001 — 都市計画区域/区域区分

**분류**: 도시계획 | 도시계획구역·시가화구역·시가화조정구역 경계.

23구 내는 전역 시가화구역이므로 구분 실익 낮음.  
다마지역·수도권(신주쿠 → 타치카와 → 하치오지 등) 분석으로 확장 시 필수.

#### XKT011 — 福祉施設 / XKT017 — 図書館 / XKT018 — 市区町村役場等

시설 포인트 단독으로는 분석 임팩트 낮음. XKT010(의료기관)과 묶어 "생활 편의성 종합 지수"를 구성할 때 보조 레이어로 활용.
